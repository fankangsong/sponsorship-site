这是本站**第一篇随笔**，用于验证 Markdown → HTML 的完整构建链路：

1. frontmatter 由 gray-matter 解析（标题、日期、摘要）
2. 正文由 marked 渲染为 HTML
3. 构建脚本生成 `/posts/hello-world/` 详情页，并加入列表与 sitemap
4. 页面用到的每个汉字都会被收集进字体子集，重新构建后字体文件随之更新

比如这个「齉」字——它只出现在这篇文章里。如果页面上它能以老宋体正常渲染，就说明动态子集化正确覆盖了这个生僻字。

> 修改本文件任意内容并 `git push`，站点会在一两分钟内自动重建上线——这就是本站的全部更新方式。

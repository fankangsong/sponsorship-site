# 全站设计规范与指导

> 依据：首页设计稿 `docs/design/index-page.png`。
> 一句话概括这套设计：**纸上墨字** —— 白纸为底、老宋竖排、灰阶成层次、朱红一点作印。

---

## 1. 设计原则

1. **留白即版式**：不靠卡片、边框、阴影划分区域，靠空白与字号对比。
2. **竖排为魂，横排为用**：首页 hero、导航、标题、落款用竖排（`writing-mode: vertical-rl`，从右往左）；长文正文（随笔详情等）保持横排，保证阅读效率与可访问性。
3. **墨分五色**：只用灰阶表达层次，全站唯一彩色是印章朱红。
4. **克制**：无渐变、无投影、无圆角大卡片、无图标；装饰只允许"细线"与"印章"两种。

---

## 2. 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#fdfdfa` | 页面底色（近纯白的暖白，与现有 `#faf8f4` 区分，更"纸"） |
| `--paper-raise` | `#ffffff` | 图片衬底、代码块底 |
| `--ink-1` | `#3a3a38` | 标题、正文主色（浓墨） |
| `--ink-2` | `#6b6a66` | 次要正文、摘要（中墨） |
| `--ink-3` | `#9b988f` | 导航、日期、辅助信息（淡墨，即设计稿中的浅灰） |
| `--ink-4` | `#c4c0b6` | 占位/禁用、极淡注释 |
| `--seal` | `#b03a2e` | 印章朱红：hover 强调、落款印章、当前页指示 |
| `--line` | `#e6e3da` | 分隔细线（1px，仅此一种线色） |

规则：
- 除 `--seal` 外禁止引入任何彩色（包括链接蓝色）。
- 文字与背景对比度：正文（`--ink-1/2`）需 ≥ 4.5:1；`--ink-3` 只允许用于 ≥ 14px 的辅助信息，不得用于正文。
- hover 的唯一表达方式：文字变 `--seal`，或淡墨变浓墨。**不使用下划线动画以外的背景色变化**。

---

## 3. 字体

### 3.1 字族

```css
--font-serif: "LXGW WenKai", "Noto Serif SC", "Source Han Serif SC",
              "Songti SC", "SimSun", serif;   /* 沿用 fonts/ 子集化产物 */
--font-mono: "Sarasa Mono SC", ui-monospace, monospace;  /* 代码 */
```

- 全站（含代码注释外的 UI 文案）只用宋体系衬线；`--font-mono` 仅用于 `code/pre`。
- 不使用无衬线字体做任何标题。

### 3.2 字号与行高（横排场景）

| 级别 | 字号 | 行高 | 字重 | 备注 |
|---|---|---|---|---|
| h1 | 30–36px | 1.5 | 600 | 页面标题，不加粗到 700 |
| h2 | 22px | 1.6 | 600 | 区块标题，前面可加竖排小字或印章点缀 |
| h3 | 17px | 1.6 | 600 | 卡片题名 |
| 正文 | 16px | 2.0 | 400 | 行高必须宽松（ ≥ 1.9） |
| 辅助 | 13–14px | 1.8 | 400 | 日期、摘要，用 `--ink-3` |

### 3.3 竖排场景（首页 hero、导航）

```css
.vertical {
  writing-mode: vertical-rl;
  text-orientation: upright;   /* 中文直立；标点随 writing-mode 自然处理 */
  letter-spacing: 0.35em;      /* 设计稿字距明显，0.3–0.4em */
  line-height: 2.4;            /* 列间距 = line-height，形成稿中宽绰列距 */
}
```

- 竖排文字一律 **`--ink-2` 或 `--ink-3`**，不用浓墨，还原稿中"淡墨"气质。
- 多列竖排的阅读方向为**从右往左**：最右列是第一句（导航），依次向左。
- 竖排块高度以内容自然断行为准，不强行等高。

---

## 4. 版式与间距

- **页面栅格**：内容最大宽度 `720px` 居中；首页 hero 可放宽至 `960px` 以容纳竖排多列 + 右侧导航。
- **留白**：采用 8px 基准但整体放大——区块间距 ≥ 64px，页面上下留白 ≥ 96px。宁多勿少。
- **分隔**：区块之间默认**只用空白**；必须分隔时用 1px `--line` 细线，线长不超过内容宽的 1/3，或干脆用居中短横 "─"。
- **对齐**：横排区域左对齐；竖排区域顶部对齐（即竖排的"起点"）。

---

## 5. 组件规范

### 5.1 导航（对应稿中最右列"首页 随笔 摄影 跑步 旅行 香香的画"）

- **桌面端**：固定于右侧的竖排列，`position: fixed; right: 48px; top: 48px`，列间距由 `line-height: 2.4` 提供。
- 当前页：文字 `--seal` 或旁加一枚 4px 朱红方点；非当前页 `--ink-3`，hover 变 `--ink-1`。
- **移动端**：退化为顶部横排一行，`--ink-3`，字距 0.2em，去掉汉堡菜单。

### 5.2 首页 Hero

- 结构：右侧竖排导航 → 正文竖排多列自右向左 → 文末左下角落款。
- 落款 = 一枚印章（见 5.6）+ 一行竖排小字（站名/年份）。
- hero 区域无 h1 大标题横排时，站名以竖排最大字号（36px）出现在首列。

### 5.3 列表（随笔列表）

- 去掉现有整行 `border-bottom`，改为：**日期（`--ink-3`，小号）+ 标题（`--ink-1`）**同行，行距 ≥ 2.2。
- 悬停：标题变 `--seal`。
- 如需分隔，仅用 24px 空白。

### 5.4 卡片（字帖橱窗）

- **去卡片化**：删除边框、圆角、底色。图片直接呈现，题名与日期置于图下方，左对齐。
- 图片悬停：`opacity: 0.85` 或 `filter: grayscale(20%) → 0`，不加阴影缩放。
- 栅格间距放大到 `32px`，`minmax(200px, 1fr)`。

### 5.5 文章详情

- 正文横排、`16px/2.0`、`--ink-1`，段距 = 1em。
- 引用块：去掉左侧粗边框，改为整段 `--ink-2` + 首行前置一枚小号朱红引号或竖线（1px `--line` 可保留但改细为 2px 内）。
- `code`：底 `--paper-raise`，1px `--line` 边框代替现有色块背景。

### 5.6 印章（全站唯一装饰元素）

- 形制：正方形或竖长方形，朱红 `--seal` 底、纸色字，或朱红描边空心；内文 1–4 字（站名/斋号）。
- 尺寸：20–32px 见方；只出现在**落款**（hero 文末、文章结尾、页脚）处，每页 ≤ 1 枚。
- 实现优先用内联 SVG 或字体字符，避免额外图片请求。

### 5.7 页脚

- 一行横排小字（`--ink-3`，13px）：版权 + 备案/RSS 等链接，链接 hover 变 `--seal`。
- 可在页脚左侧放一枚 20px 小印章作为全站收束。

---

## 6. 交互与动效

- 全站过渡统一：`transition: color .2s ease, opacity .2s ease;`，不做位移/缩放/弹跳动效。
- 链接 hover 一律 **变色不加粗**；正文内链接可加 `text-underline-offset: 4px; text-decoration-thickness: 1px` 细下划线。
- 首页 hero 可加一次性入场：各竖排列 `opacity 0 → 1`，自右向左依次延迟 80ms，总时长 < 800ms，且尊重 `prefers-reduced-motion`。

---

## 7. 响应式

| 断点 | 处理 |
|---|---|
| ≥ 1024px | 完整竖排 hero + 右侧固定竖排导航 |
| 640–1024px | 导航转为顶部横排；hero 保留竖排但减少列数（可拆成两栏并排的竖排块） |
| < 640px | hero 改为横排短段落（竖排在窄屏上列数过少、观感崩坏）；字距降为 0.1em；全站字号正文 15px |

---

## 8. 无障碍与底线

1. `--ink-3` 只用于辅助信息；所有正文内容对比度 ≥ 4.5:1。
2. `writing-mode` 区域需保证 DOM 阅读顺序与视觉阅读顺序（右→左）一致：DOM 中先写导航、再写第一列。
3. 印章装饰需 `aria-hidden="true"`；`img` 必须有 alt。
4. 焦点态：`:focus-visible { outline: 1px solid var(--seal); outline-offset: 3px; }`，全站唯一 focus 样式。

---

## 9. 落地路线（对照现有 `src/assets/css/style.css`）

按优先级分四步，每步独立可发布：

1. **Token 化**：在 `style.css` 顶部定义第 2 节 CSS 变量，替换现有写死的颜色值（`#2c2a26 → var(--ink-1)` 等），此步不改观感结构。
2. **导航与 hero 竖排化**：新增 `.vertical` 工具类；改 `src/app/components/Nav.jsx` 为右侧竖排固定；`src/app/pages/Index.jsx` 的 hero 改竖排 + 落款印章。
3. **去卡片化与列表重排**：按 5.3 / 5.4 调整 `.card`、`.post-list`；删除多余边框底色。
4. **细节**：印章组件、入场动效、`prefers-reduced-motion`、移动端断点收尾。

每步完成后运行 `pnpm build` 并在 `pnpm dev` 下核对首页与任一随笔详情页。
